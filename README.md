# LPM 表项管理（TCAM + SRAM）

TCAM 存 key 和 mask，SRAM 按行号存 payload。IPv6 /128 的 key 加 mask 共 256 bit，超过单行位宽，一条表项需要跨越数行。

跨行之后要同时处理三件事：拆分行数、续行与首行的绑定方式、删除后留下的空闲区如何补齐。分配不当会使实际可装路由数远低于标称容量。

地址扫描由 `python tests/test_sweep.py` 执行。代码不依赖厂商 SDK，具备 Python 3.9 与标准库即可运行。

![查表流水](docs/images/lookup-pipeline.svg)

## 表结构

路由统一为 `(key, key_len, payload)`。IPv4 左移 96 位对齐到 128 位空间，与 IPv6 共用一张表：

```
IPv4 10.1.2.0/24    key = 0x0a010200 << 96   key_len = 24
IPv6 2001:db8::/64  key = 2001:0db8::0000    key_len = 64
```

远端模式的差别只在 payload，key 与匹配语义均不变。

一条表项占多少行：

```
rows = ceil(round_up(key_len, 8) / cell_bits) + ceil(payload_bits / cell_bits)
```

`key_len` 按 8 bit 向上取整，否则短前缀的 mask 无法在行内表达。

## 多行拼接

表项跨多行时，首行置 `VLD=1`、续行置 `VLD=0`。续行由首行的 `span` 字段带入。匹配器只在 `VLD=1` 的行中取最长前缀，命中后按 `span` 校验后续行是否完整。

只匹配到后半段的行不计为命中。优先级在表项维度比较，与行数无关。

## cell 位宽

实测使用 6000 条混合前缀（60% IPv4 /8~/24，40% IPv6 /32~/128）。行预算固定，过程中包含 40% 的插入与删除。三档位宽分别执行一次，结果如下：

| cell 位宽 | 平均 span | 位利用率 | 可容纳条目 | 碎片阻塞 |
|---|---|---|---|---|
| 32 bit | 2.71 | 0.851 | 2117 | 1490 |
| 48 bit | 2.44 | 0.625 | 2353 | 1429 |
| 64 bit | 2.22 | 0.515 | 2551 | 1394 |

位宽较小时，位利用率较高，但单条表项占用的行数多、所需的连续空间也长。碎片增多后，插入会失败。位宽增大可以容纳更多条目，代价是填充位增加。IPv4 /8 存入 64 bit 行只占 8 位，其余 56 位为空。

选型取决于硬件先耗尽行数还是先耗尽总位数。

## 删除与压缩

删除变长表项会留下与其长度相等的空闲区。空闲区尺寸取决于被删表项的长度，各段之间不连续，长表项通常无法获得足够的连续空间。

删除时只置标记位，碎片率超过阈值后再执行整段压缩。阈值取 0.25。低于该值时，零星空闲区仍可被短表项占用。高于该值时，连续区域不再自然形成，出现空闲总量足够但无法插入一条 /128 的情况。

具体分配采用 best-fit，在空闲区中选取长度最接近所需行数的一段。

## 验证

错误集中在几个窄带上：前缀长度 0/1/31/32/127/128、相邻前缀重叠、本地刚溢出到远端的那一条、压缩进行到一半的中间态。常规流量不会涉及这些位置。

典型用例无法覆盖上述位置，因此改为按前缀长度分层扫描。每层取四个探测点，分别为网络地址本身、加一、减一与掩码外翻转一位。

期望值取自另一份独立编写的朴素最长匹配，遍历全部前缀后取最长者。该实现耗时较长，但与被测实现没有共用代码，结果不一致即说明模型有误。

失败时输出前缀长度、探测类型、地址、期望值与实际值、锚行行号与 span。

```
python tests/test_sweep.py
python tests/test_sweep.py --len 127
```

## 文档检查

`tools/prose_check.py` 检查中文表述。规则取自 `yikeke/zh-style-guide` 的句子与语言风格章节，以及 `op7418/Humanizer-zh` 的模式清单。来源逐条写在脚本开头。

```
python tools/prose_check.py README.md docs/architecture.md docs/test-method.md
```

覆盖项：拟人化比喻、口语用词、一逗到底、碎句堆砌、超长句、模板句、反问与感叹。命中任意一条即返回非零退出码，CI 中会阻断合并。
